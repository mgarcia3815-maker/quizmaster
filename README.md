# QuizMaster

Cuestionario web para practicar HTML, CSS y JavaScript, con tres niveles de dificultad y retroalimentación inmediata. Proyecto de medio ciclo hecho solo con HTML, CSS y JavaScript nativos.

Aplicación publicada: https://mgarcia3815-maker.github.io/quizmaster/

Páginas: index.html (inicio y formulario), quiz.html (cuestionario), resultados.html (puntaje y revisión).

Accesibilidad y estándares: verificado con Nu HTML Checker, CSS Validation Service, WAVE y Lighthouse, y con prueba solo con teclado, según WCAG 2.2.

Integrantes: García Cedeño María Fernanda; Godoy Palacios Pablo Alexander.
